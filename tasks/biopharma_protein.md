窗口定义：

- 主窗口：Thermo BioPharma Finder 5.1
- 添加分析文件窗口：Add Analysis File(s)

任务流程：

0. 动作：点击 `Home` 。
   窗口：主窗口
   验证：回到 `Home` 界面。
1. 动作：点击 `Intact Mass Analysis`。
   窗口：主窗口
   验证：页面进入 `Intact Mass Analysis` 的实验配置界面。
2. 动作：点击 `Experiment Name` 右侧输入框并输入 `BioPharma test demo1`。
   窗口：主窗口
   验证：`Experiment Name` 右侧`输入框`中有输入。
3. 动作：点击 `...` 。
   窗口：主窗口 -> 添加分析文件窗口
   验证：已打开用于选择分析文件的窗口，窗口标题或界面中可见 `Add Analysis File(s)`。
4. 动作：双击 `1#_20230714133351.raw`。
   窗口：添加分析文件窗口 -> 主窗口
   验证：文件 `1#_20230714133351.raw` 已被选中或已添加到分析文件列表中。
5. 动作：点击 Default ReSpect 左侧 `选择框`。
   窗口：主窗口
   验证：Default ReSpect 左侧`选择框`处于选中状态。
6. 动作：点击 `Add To Queue`。
   窗口：主窗口
   验证：任务已加入队列，或者界面中出现队列条目、运行队列状态、提交成功提示中的任意一种。
